# World Pals — 꼬마 세계 탐험대

7~9세 어린이용 세계 수도 탐험 웹게임. 기획서: `WORLD_PALS_PLAN.md`.
현재 구현 단계: **Phase 1~4 + 도전장** (수도/국기 퀴즈, 도장·배지·꾸미기·여권·오답 복습, 세계지도, World Pals Lab, 친구에게 문제 내기).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run typecheck  # 타입 검사
npm test           # 단위 테스트 (vitest)
npm run build      # 프로덕션 빌드 (dist/)
```

Node 20+ 권장 (개발은 Node 22에서 확인).

## 구조

```
src/data/        콘텐츠(countries, questions, badges, rewards[장식] .json) — 로직과 분리, 고유 ID로 참조
src/config.ts    세션 크기, 복습 개수, 보상 수치
src/features/quiz/  quizEngine.ts(출제·보상 로직, 순수 함수), QuizPage.tsx
src/features/rewards/  rewardEngine.ts(배지 조건, 장식 해금/장착)
src/features/companions/  탐험 친구(동물) 판정 로직
src/features/challenge/  도전장(친구에게 문제 내기: 링크 코드, 만들기/받기 화면)
src/features/passport/, customization/, map/  여권, 꾸미기, 세계지도 화면 (map/worldLand.ts는 생성된 지도 데이터)
src/features/lab/  World Pals Lab (validators, importExport, labOps, labStorage + 편집기 화면)
src/lib/         saveData.ts(localStorage 저장/복구), storageKeys.ts, random.ts
src/types/       Country, Question, PlayerProgress
src/pages/       HomePage, ResultPage
```

## 설계 메모

- 콘텐츠와 플레이어 진행은 분리되어 있고, 진행 데이터는 ID만 저장합니다.
- `status: "verified"`인 국가·문제만 출제됩니다. 현재 데이터는 **개발자 일반 지식 기반 초안**이며 출처 확인 전입니다 (`src/data/SOURCES.md`).
- 별과 일일 보상은 `rewardEventIds`(`daily:날짜`)로 하루 한 번만 지급합니다. 같은 날 재플레이와 오답 복습은 별 없는 연습 모드입니다.
- 국가 도장은 연습에서도 받습니다. 연습 = 기본 도장, 오늘의 탐험 = 황금 도장이며 기본 도장은 오늘의 탐험에서 맞히면 황금으로 올라갑니다.
- 배지 조건은 `badges.json`에 데이터로 정의합니다 (지원 조건: 탐험 횟수, 발견 국가 수, 대륙별 발견 수, 푼 문제 수, 복습 정답 수).
- 별(`totalStars`)은 현재 보유량입니다. 장식 해금 시 차감되고, 이미 해금한 장식은 다시 차감되지 않습니다.
- 국기는 `flag-icons`(MIT) SVG를 국가 ID(ISO 코드)로 연결합니다. 이미지는 CSS에 넣지 않고(`assetsInlineLimit: 0`) 화면에 나온 국기만 개별 파일로 내려받고, 여권에서는 스크롤로 가까워진 국기만 받습니다. 아직 못 찾은 나라는 국기 대신 물음표 칸이라 이미지를 받지 않습니다. 첫 로드는 CSS 약 3KB + JS 약 83KB(gzip)입니다.
- 진행은 브라우저 localStorage(`worldpals.progress`)에 저장됩니다. 클라우드 백업이 아니며, 사이트 데이터를 지우면 사라집니다. 저장 실패나 깨진 데이터는 기본값으로 복구됩니다.
- Lab 플레이 테스트용 저장 키(`worldpals.lab.test.progress`)는 미리 분리해 두었습니다.

## 문제 유형

- `capital`: 나라 → 수도 4지선다 / `flag`: 나라 이름 → 국기 그림 4지선다 (답을 고르기 전에는 보기에 나라 이름이 보이지 않음)
- 한 세션에는 같은 나라가 한 번만 나오고, 비슷한 국기(호주·뉴질랜드 등)는 같은 문제의 보기로 묶지 않습니다.

## World Pals Lab (콘텐츠 편집기)

게임 화면 아래의 "🧪 제작자 도구 (Lab)" 링크 또는 주소 뒤에 `#/lab`을 붙여 엽니다. 로컬(브라우저) 전용 도구입니다.

1. 국가/문제/보상(장식·배지)을 편집합니다. 편집 내용은 브라우저에 자동 임시 저장됩니다 (`worldpals.lab.draft`).
2. '검증' 탭에서 오류를 확인합니다 (중복 ID, 없는 국가 참조, 보기 중복, 정답 중복, 음수 비용 등).
3. '가져오기/내보내기'에서 `게임 데이터 파일 4개`를 내려받아 `src/data/`의 같은 이름 파일을 교체합니다 (검증 오류가 없을 때만 가능).
4. 교체 전 '버전 사본'(브라우저 내 최대 10개)이나 백업 JSON을 만들어 두세요.
5. '플레이 테스트'는 테스트 전용 저장 키(`worldpals.lab.test.progress`)만 사용하며 실제 플레이 기록을 바꾸지 않습니다.

- 저장된 항목의 ID는 바꿀 수 없습니다 (진행 기록·문제가 ID로 연결되기 때문). 새로 만든 항목만 ID를 정할 수 있습니다.
- 초안/검수 중 항목은 게임에서 출제·지급되지 않습니다.
- 편집 내용은 브라우저 저장소에만 있으므로 지우면 사라집니다. 백업 JSON을 내려받아 보관하세요.

## 도전장 (친구에게 문제 내기)

쌍근처럼 "내가 먼저 잘 풀어야 문제를 낼 수 있고, 링크 하나로 친구가 바로 푸는" 구조입니다. **서버가 없습니다.**

- **만들기 조건**: 오늘의 탐험(보상이 있는 판)에서 5문제 중 4문제 이상 맞히면 그날 도전장을 만들 수 있습니다 (`CONFIG.challengeMinCorrect`). 연습·복습·도전장 풀이로는 열리지 않고, 다음 날에는 다시 풀어야 합니다.
- **만들기**: 도장을 받은 나라 중 3~5개를 고르고, 나라마다 수도/국기 유형과 미리 정해진 인사말 하나를 고릅니다.
- **링크 형식**: `https://<주소>/#/c/JPf.CNc.ITc.ESc~2` — 나라 코드 2글자 + 유형(c=수도, f=국기), 점으로 구분, `~`뒤는 인사말 번호. 문제와 오답 보기는 앱의 문제 데이터에 이미 있어서 링크에는 ID만 담기고, 누가 열어도 같은 문제가 나옵니다.
- **안전**: 링크에 **직접 쓰는 글이 없어** 이름·개인정보·부적절한 문구가 들어갈 수 없습니다. 잘못되었거나 지원하지 않는 링크(형식 오류, 없는 나라, 출제 제외 나라, 중복)는 앱이 멈추지 않고 안내만 합니다.
- **받기**: 링크를 열면 소개 → 풀기 → 결과(⭕❌ 줄)로 이어집니다. 도전장은 오늘의 탐험이 아니라 연습으로 처리되어, 맞힌 나라의 기본 도장과 오답 복습 기록이 반영됩니다. 결과 문구를 복사해 친구에게 보낼 수 있습니다.
- **보너스 별(푸는 사람에게만)**: 친구의 도전장을 **처음** 풀 때 맞힌 문제 하나당 ⭐ 1개(`CONFIG.challengeStarsPerCorrect`), **하루 최대 6개**(`challengeBonusDailyMax`). 같은 도전장은 한 번만(문제 순서·인사말만 다른 링크도 같은 도전장), **내가 만든 도전장은 같은 기기에서 풀어도 없음**, 오늘 상한을 다 채운 날에는 푼 것으로 기록하지 않아 다음 날 받을 수 있습니다. 서버가 없어서 "친구가 맞히면 만든 사람이 별을 받는" 방식은 불가능합니다. 단, 다른 브라우저/기기에서 본인이 만든 링크를 풀면 별을 받을 수 있으므로(서버 없이는 막을 수 없음) 하루 상한으로 영향을 제한합니다.
- **한계**: 서버가 없어서 친구가 풀었는지/점수는 만든 사람에게 돌아오지 않습니다(결과를 직접 보내야 함). 링크를 가진 사람은 누구나 열 수 있습니다. 링크는 만든 날 이후에도 계속 열립니다.
- 새 문제 유형이나 나라가 추가되어도 기존 링크는 그대로 열립니다. 나라를 삭제하거나 `verified`를 해제하면 그 링크는 "문제를 찾을 수 없어요"로 안내됩니다.

## 탐험 친구 (나라별 동물)

- 나라의 도장을 받으면 그 나라의 동물 친구를 만나고(결과 화면에 "새 친구를 만났어요!"), 꾸미기에서 한 마리를 골라 폭시 옆에 데려갑니다. 25개 나라에 하나씩, 이모지가 겹치지 않게 정했습니다.
- 못 만난 친구는 실루엣과 `???`로만 보이고, 접근성 이름에는 나라 대신 대륙만 나옵니다.
- 데이터는 `src/data/companions.json` (ID 기반, `countryId`로 나라와 연결). Lab의 보상 > 탐험 친구 탭에서 편집·검증·내보내기를 할 수 있습니다. 예전 백업 파일처럼 `companions`가 없어도 가져올 수 있습니다.
- 설명은 사실에 가까운 짧은 문장으로 쓰고, 공식 국가동물인지는 각 항목의 `sourceNote`에 적었습니다. **공식 지정 여부는 대부분 출시 전 확인이 필요합니다.**
- 이모지는 Windows 10에서도 보이도록 Unicode 12 이하만 사용했습니다.

## 공유 미리보기와 아이콘

- 링크를 카카오톡·메신저에 붙이면 보이는 카드(제목, 설명, 큰 이미지)는 `index.html`의 `og:*` 메타 태그와 `public/og-image.jpg`(1200×630)가 만듭니다.
- 이미지 주소는 절대 주소여야 해서 `https://world-pals.vercel.app/`로 적어 두었습니다. **배포 주소(도메인)가 바뀌면 `index.html`의 `og:url`, `og:image`, `twitter:image`를 함께 바꿔야 합니다.**
- 카카오톡은 한 번 만든 미리보기를 캐시합니다. 이미지를 바꿨는데 예전 모습이 나오면 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 해당 주소의 캐시를 초기화하세요 (로그인 필요).
- 미리보기는 주소의 `#` 앞부분만 읽기 때문에, 도전장 링크(`/#/c/...`)도 모두 같은 카드가 나옵니다. 링크마다 다른 카드를 보여 주려면 서버(또는 Vercel 함수)가 필요합니다.
- 마스코트 '폭시'는 이 프로젝트용으로 직접 그린 SVG(`public/brand/fox.svg`)입니다. 파비콘, 홈 화면 아이콘(`apple-touch-icon.png`, `icon-*.png`), `manifest.webmanifest`가 같은 그림을 씁니다. 게임 안의 캐릭터는 아직 이모지 🦊입니다.

## 세계지도

- 등장방형 2D SVG(`src/features/map/worldLand.ts`) 위에 국가 위도/경도로 마커를 올립니다. 발견한 나라는 국기(황금/기본 도장 테두리), 아직은 물음표입니다.
- 나라가 모여 있어 겹치므로 대륙 버튼으로 확대해서 봅니다. 마커는 실제 버튼이라 키보드/터치로 열 수 있습니다.
- 지도 데이터 출처/라이선스는 `src/data/SOURCES.md` 참고.

## 배포 (Vercel)

정적 사이트라 서버가 필요 없습니다.

1. GitHub 저장소를 Vercel에서 Import (Framework: Vite 자동 감지, Build `npm run build`, Output `dist`).
2. **Lab은 배포본에서 기본으로 숨겨집니다.** `#/lab` 주소와 홈의 링크가 모두 없어집니다. 배포본에서도 Lab을 쓰려면 환경변수 `VITE_ENABLE_LAB=true`를 설정하고 다시 빌드하세요. (Lab은 편집 내용을 그 브라우저에만 저장하며, 게임 데이터에는 파일 교체로만 반영됩니다.)
3. 로컬에서 배포본 확인: `npm run build && npm run preview`.

## 알려진 한계

- 진행 기록은 브라우저 localStorage에만 있습니다. 같은 브라우저의 여러 탭은 `storage` 이벤트로 동기화되고, 세션을 끝낼 때는 저장소의 최신 기록 위에 결과를 더하므로 별/도장이 덮어써지거나 중복 지급되지 않습니다. (저장소를 읽을 수 없는 환경에서는 탭끼리 공유되지 않습니다.)
- 퀴즈 도중 새로고침하면 그 세션은 처음부터 다시 시작합니다.
- 국가/수도 데이터는 출처 검증 전 초안입니다 (`src/data/SOURCES.md`).
